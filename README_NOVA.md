# AST NOVA — Student Focus OS

Separate project with unique filenames.

Features:
- Focus/Pomodoro 25/50/90/custom
- Subject + topic logging
- Automatic session completion -> minutes, XP, sessions, weekly progress
- Study challenges tied to Focus
- Study Rooms and leaderboard
- Daily/weekly goals
- Arabic / Français / English with RTL
- Responsive UI
- No dependency required: open `nova.html`

This is a standalone front-end prototype. Cloud accounts, realtime rooms and persistent multi-user data can be connected to Supabase later.

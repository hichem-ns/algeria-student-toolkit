# 🇩🇿 Algeria Student Toolkit

A polished, lightweight student dashboard made for Algerian university students.

## Features

### 📊 University-style grade calculator
- Module-based calculation
- Continuous assessment / TD / TP + exam
- Configurable CC weighting: 30%, 40%, 50% or 60%
- Coefficient weighting
- Semester average
- Modules ≥ 10 counter
- Estimated credits
- Compensation explanation
- Local persistence

> Academic rules can differ between faculties and formations, so the CC/exam weighting is configurable rather than hard-coded.

### ⏱️ Focus Room
- 25-minute focus
- 5-minute short break
- 15-minute long break
- Automatic cycles
- Session counter
- Focus-minute tracking
- Local persistence

### 📝 Student planner
- Tasks with priority
- Complete / pending filters
- Top 3 daily priorities
- Local persistence

### 🎨 UX
- Responsive design
- Light / dark mode
- Mobile friendly
- No account
- No backend
- GitHub Pages ready

## Run

Open `index.html` directly in a browser.

## GitHub Pages

Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.

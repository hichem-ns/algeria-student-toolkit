# 🇩🇿 Algeria Student Toolkit

A lightweight, free toolkit made for Algerian students.

## Features

- 📊 Weighted grade / average calculator
- ⏱️ 25-minute Pomodoro timer
- 📝 Revision todo list with local persistence
- 📅 Three-priority daily planner
- 🎓 Quick access to useful student resources
- 📱 Responsive mobile-first interface
- 🔒 No account required; todo data stays in the browser

## Run locally

No build step is required. Open `index.html` in a browser.

## Deploy

This is a static website and can be deployed with GitHub Pages.

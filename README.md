# AST V6 — Integrated Student OS

This version is built on the AST V5 project structure, not a separate prototype.

## Main improvements
- Focus Studio redesigned as the central study hub.
- Pomodoro 25/5, 50/10, 90/15 and custom settings.
- Subject + topic capture for each session.
- Study challenges directly inside Focus.
- Study Rooms / group competition concept.
- Session history, daily focus goal, XP and streak tracking.
- Arabic / Français / English selector with RTL support.
- Cleaner navigation and responsive mobile UI.
- Existing AST modules are preserved: planner, grades, notes, timetable, flashcards, profile and Supabase-ready storage.

## Run
Open `index.html` in a browser or deploy the folder to GitHub Pages.

## Production note
The local mode is still available. For real multi-user rooms, live leaderboards, chat, profiles and cloud sync, connect the existing Supabase configuration and schema.

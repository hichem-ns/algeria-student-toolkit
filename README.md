# AST Focus V6

A clean student-focused Pomodoro / Study Center prototype.

## Included
- Pomodoro 25/50/90/custom
- Study subject + topic
- XP, focus stats, streak concepts
- Study challenges
- Study rooms + leaderboard
- Daily/weekly goals
- Smart-session suggestion
- Arabic / Français / English
- RTL support for Arabic
- Responsive mobile layout

## Run
Open `index.html` in a browser.

## Next production step
Connect Supabase Auth, Database, Storage and Realtime to turn Rooms, accounts, profiles and leaderboards into real cloud features.
